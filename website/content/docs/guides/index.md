Choose a starting point by task. [Installation](docs/guides/installation) covers dependencies; the [Quickstart](docs/guides/quickstart) connects a generated login model to Flutter; [Dynamic lists](docs/guides/dynamic-lists) and [Multi-step forms](docs/guides/wizard) demonstrate common workflows.

## Choose a track

- [Schema](docs/schema) explains pure-Dart validation and optional typed model generation. Use it to define rules and generated field references.
- [Form State](docs/form-state) documents the framework-independent controller, field handles, validation visibility, and collection operations.
- [Flutter](docs/flutter) covers widgets, context bindings, selective rebuilds, lists, and submission behavior.

The schema and controller layers can be used and tested without Flutter. Flutter is an optional binding layer; the pure-Dart form state remains independent of mounted widgets.
